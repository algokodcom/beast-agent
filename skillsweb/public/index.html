Beast Agent'a nasıl kurulur?

Bu mağaza, uygulamanın içindeki Skills Store ile aynı indeksi kullanır — burada bulduğun skill'i saniyeler içinde kur.

1

Beast Agent'ı kur

Terminalde tek komut: npm i -g beast-agent. Windows için Node.js yeterli — ek kurulum yok.

2

Skills Store'u aç

Uygulamada üst bardaki mağaza düğmesine bas — Trending / Stars / Upload sekmeleri seni bekliyor.

3

Bul ve “İste Kur”

Skill'i ara, İste Kur'a bas. Ajan o yeteneği anında kullanmaya başlar — restart gerekmez.

Kendi skill'ini yayınla

Beast Agent → Skills Store → Upload sekmesinden klasörünü (SKILL.md zorunlu) yükle; JSON'unu GitHub issue/PR ile store/skills.json dosyasına ekle. Topluluk burada ve uygulama içinde görür.
